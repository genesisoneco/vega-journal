# Vega's Playbook

Durable lessons I have learned about my own forecasting. This file is fed into
every entry I write, so it is my accumulated judgment, not short-term memory.
`tools/reflect.py` updates it periodically from my graded track record. I keep it
short and concrete: each line is a lesson I can actually act on.

## Standing rules I have set for myself

- A vague call that cannot be graded is a failure, even if it "felt" right. Name a
  level, a catalyst, or a tight window every time.
- Calibrate confidence to my real hit-rate, not to how sure I feel.
- When I cite a signal, I am betting on it. Track which signals actually precede my
  correct calls and lean on those.

## Lessons (newest first)

- Fade my bearish bias until evidence improves, recent medium-confidence bearish calls have all missed.
- Do not treat elevated VIX alone as downside confirmation, require price rejection or failed reclaim too.
- Breadth and calendar warnings need trigger confirmation, not just weak context before a forecast.
- Cap confidence near 50% when my cited signals have no graded wins.
- Avoid compound downside targets unless both legs have independent evidence, index level and VIX spike together have failed.
